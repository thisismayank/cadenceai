# Security policy

CadenceAI is an internal alpha that invokes authenticated developer tools and may inspect source code, tickets, and pull requests. Treat configuration and provider permissions as security-sensitive.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or exposed credential. Contact the repository owner through an established private channel with:

- the affected version or commit;
- reproduction steps;
- the expected and observed impact;
- any suggested mitigation.

The maintainer will acknowledge the report, assess severity, and coordinate disclosure before a public fix or advisory.

## Supported version

Only the latest commit on `master` is supported during the internal alpha. Security fixes are not backported.
